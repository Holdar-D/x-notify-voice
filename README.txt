# X 新消息语音提醒（Edge / Chrome 扩展）

X 有新私信或新通知时，语音播报「您有新的消息，请及时回复」，
同时弹一条系统通知。

## 原理

扩展跑在你自己的浏览器里，用你已登录的 X 会话（cookie + ct0）
每分钟轮询一次 X 的通知和私信接口，有新内容就播报。
不经过任何第三方服务器，不保存账号密码。
首次安装只记基线，不会把旧消息报一遍。

## 安装（Edge）

1. 把 x-notify-voice.zip 解压到一个固定文件夹（不要放下载文件夹随手删）
2. Edge 打开 edge://extensions
3. 左下角打开「开发人员模式」
4. 点「加载解压缩的扩展」，选刚才解压的文件夹
5. 先在 Edge 里登录 x.com，扩展就开始工作了

Chrome 同理，把 edge://extensions 换成 chrome://extensions。

## 设置

点工具栏里的扩展图标：
- 私信提醒 / 通知提醒：各开各的，都能关
- 开启提醒：总开关，关掉就不提醒（语音、横幅、角标都停）
- 私信播报发信人名字：只对私信，播报"某某发来私信"（可关；自己发的私信不误报）
- 没看就再提醒一次：只重复一次（可关）
- 正在看 X 时不语音（横幅照常）
- 点系统通知直接打开 X：私信→私信页，通知→通知页
- 角标：未看的新消息数，点开弹窗或点通知后清零
- 登录过期提醒：X 掉登录时语音加横幅提醒一次，重新登录后恢复
- 通知备用接口：主接口挂了自动切计数接口降级提醒（不分类型），弹窗通知行会标【备用接口】
- 音量：弹窗里可调（0–100%）
- 提醒语音：想改播报词直接改
- 语气：正常 / 蜡笔小新（录音）/ 温柔慢速
- 检查间隔：1 / 2 / 5 / 10 / 30 分钟、1 小时，或自定义分钟数（1–1440）
- 试听语音：点一下就播一遍
- 立即检查：马上查一次

## 注意

- Edge 必须开着、且登录着 x.com，扩展才能工作；Edge 关了就没提醒
- 语音用的是 Mac 系统自带的中文语音；选蜡笔小新时放一段录音（默认提醒词那句）
- 想停就点「管理扩展」关掉它，或直接删掉

## 文件

- manifest.json（MV3 清单）
- background.js（轮询 + 语音 + 通知）
- popup.html / popup.js（设置弹窗）
- offscreen.html / offscreen.js（播录音，MV3 专用）
- shinchan-reminder.mp3（蜡笔小新提醒录音）
- icon16/48/128.png（图标）
