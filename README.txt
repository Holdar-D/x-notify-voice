# X 新消息语音提醒（Edge / Chrome 扩展）

X 有新私信或新通知时，语音播报「您有新的消息啦，请及时回复」，
同时弹一条系统通知。

## 原理

扩展跑在你自己的浏览器里，用你已登录的 X 会话（cookie + ct0）
每分钟轮询一次 X 的通知和私信接口，有新内容就播报。
不经过任何第三方服务器，不保存账号密码。
首次安装只记基线，不会把旧消息报一遍。

## 安装（Edge）

1. 把 x-notify-voice.zip 解压到一个固定文件夹（不要放下载文件夹随手删）
2. Edge 打开 edge://extensions
3. 左下角打开「开发人员模式」
4. 点「加载解压缩的扩展」，选刚才解压的文件夹
5. 先在 Edge 里登录 x.com，扩展就开始工作了

Chrome 同理，把 edge://extensions 换成 chrome://extensions。

## 设置

点工具栏里的扩展图标：
- 私信提醒 / 通知提醒：各开各的，都能关
- 提醒语音：想改播报词直接改
- 检查间隔：1 / 2 / 5 分钟
- 试听语音：点一下就播一遍
- 立即检查：马上查一次

## 注意

- Edge 必须开着、且登录着 x.com，扩展才能工作；Edge 关了就没提醒
- 语音用的是 Mac 系统自带的中文语音
- 想停就点「管理扩展」关掉它，或直接删掉

## 文件

- manifest.json（MV3 清单）
- background.js（轮询 + 语音 + 通知）
- popup.html / popup.js（设置弹窗）
- icon16/48/128.png（图标）
